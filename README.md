## 研究与探索方向

以计算机视觉（Computer Vision）为主要研究方向，关注生成式人工智能（AIGC）、多模态理解及其在垂直领域中的应用。

- **图像生成与编辑**：关注扩散模型、LoRA 微调、可控图像生成及局部细节保持。
- **目标检测与数据增强**：探索基于生成模型的小样本数据增强方法，以及生成数据对 YOLO 等视觉检测模型的性能影响。
- **多模态理解**：关注视觉语言模型（VLM）、手写文档理解、数学推理及图形语义理解。
- **模型微调与轻量化部署**：探索垂直领域多模态模型的微调、推理优化及可靠性评测。
- **AI 教育应用**：结合多模态理解与软件工程技术，探索理工科手写作业的自动批改、错误定位及智能批注。
