# 嗨，我是游衿Yueri。

我在西电读研，平时做计算机视觉，也写给老师和学生用的软件。看论文时弄懂的东西，写程序时踩过的坑，都收在自己的小院里。

### 最近在研究

- **图像生成**　我喜欢能动手控制的生成方法。给扩散模型一张参考图，或者圈出想改的地方，看看能把画面改到什么程度，又能保住多少原来的细节。
- **目标检测**　用 YOLO 在图里找目标，看看它认出了什么、框在了哪里。比起只看一个总分，我更喜欢把漏掉和认错的图摆在一起看。
- **智慧教育**　手写作业里，一道推导写到下一页很常见。我在做的批改工具要把两页答案接起来，逐题评分，再把批注落回原稿，交给老师复核。

### 平时写的软件

- **前端**　用 Vue 3 和 TypeScript 做交互。学生交作业、查成绩，老师点开某一道题，对着原稿看批注、改分数。
- **后端**　用 Python 和 FastAPI 写接口，PostgreSQL 保存作业和成绩。批改慢，就用 Celery 和 Redis 把任务排到后台，页面可以先把进度告诉学生。
